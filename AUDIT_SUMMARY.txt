## Quick Start

### For Testing
```bash
# Windows
python auto_test.py

# Linux/macOS
python3 auto_test.py
```

### For Deployment
```bash
# Create .env file with your credentials
cp .env.template .env
# Edit .env with your actual credentials

# Linux/macOS
./setup.sh
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### For Docker
```bash
docker build -t security-audit .
docker run -e EXTERNAL_API_KEY="key" -e DB_USER="user" -e DB_PASS="pass" -e SERVICE_TOKEN="token" -e RSA_PRIVATE_KEY="key" -v $(pwd)/logs:/app/logs security-audit
```
